# Shared writing rules

Preserve the result, scope, prerequisites, decisions, permissions, boundaries
and acceptance criteria. Give each recipient the necessary context directly or
through exact, accessible sources with an explicit reading instruction. Never
assume conversation history.

Define full completion, the necessary verification and concrete missing inputs
or decisions. Continue already authorized work. A question or assessment alone
does not authorize changes. A writing profile changes neither task risk nor
required model, role or authority.

Write directly, concretely and briefly. Keep each rule at its owner. Use
paragraphs and lists when they improve understanding. For longer work, report
meaningful findings and next steps briefly. Make the final result, actual
checks and remaining limits understandable on their own. Preserve required
result schemas and delivery contracts.
