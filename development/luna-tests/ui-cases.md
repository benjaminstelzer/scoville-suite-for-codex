# UI cases

One fresh Luna context per case, answer key hidden. Cases 01-05 use discovery
metadata only and ask for applicability/owner. Cases 06-25 use the built UI
package and ask for reference routes, allowed next action and evidence limits.
All states are hypothetical. Do not launch browsers or change a project.

01. Optimize a backend SQL query without changing any interface.
02. Implement keyboard navigation for a framework dropdown.
03. Develop a visual art direction for a poster, without implementation.
04. Implement a supported WordPress plugin-owned wp-admin settings page. Use the local WordPress adapter within the single UI Skill.
05. Correct the meaning of supplied prose without changing its presentation.
06. A hypothetical ownership-only question has a known framework owner and no open fallback, quality or proof judgment. Which references are needed?
07. Only ownership/fallback is unresolved for a new interface. No quality or implementation judgment is requested.
08. A settled UI decision has existing evidence to evaluate. No implementation owner or quality question remains open.
09. An approved product decision settles typography and hierarchy. UI is asked to implement it in the known framework.
10. No visual owner exists for a new interface. May UI proceed?
11. A local pattern repeats throughout the repository, but evidence says it was accidental and obsolete.
12. A token exists, but a custom styling override is proposed without checking the component API.
13. A screenshot file exists, but nobody has viewed it. Does it prove rendered quality?
14. A viewed screenshot shows the page, but keyboard behavior has not been exercised.
15. A build passes. The task asks whether mobile text is clipped.
16. An approved product decision has an unresolved field. May UI silently choose a replacement?
17. An actual component limitation conflicts with an approved visual decision.
18. An audit-only request finds an obvious spacing defect that could be fixed immediately.
19. Two controls have equal outer height, but one label appears lower. Is border-box equality enough to dismiss the difference?
20. With a 16px root font, one element's width is 2rem and another's is 32px. The root font then becomes 20px while other conditions stay fixed. Calculate the widths and assess whether the declarations are interchangeable.
21. A consistency review checks only the first viewport, skipping known content below it and a relevant open tab.
22. The user explicitly requests polished desktop and mobile presentation with realistic populated content. Only the desktop populated state and mobile error state were inspected. Which required proof is missing?
23. A control supports pointer and keyboard input that share selection state. Both methods pass separately from clean state.
24. A project offers source inspection but no usable renderer or interactive runtime. The user requests a complete visual and accessibility pass.
25. An approved product decision protects hierarchy, a framework component cannot express one non-binding target, a global override could imitate it, and only source/build evidence exists. State ownership, routing, next action and permissible completion claims without redesigning or inventing proof.
