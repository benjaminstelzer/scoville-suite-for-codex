# Test author review

This review covers the retained case sets for Code, Handoff, Plan, UI, Workflow,
WordPress UI and the three Ask representatives. Each set keeps prompts separate
from its expected results. The review checks that cases exercise activation,
non-activation, routing, rule application and honest evidence boundaries.

The case review is an author check of the fixtures. It is not model execution,
runtime proof or release approval. The final release gate must bind any model
results to the exact package bytes being published.
