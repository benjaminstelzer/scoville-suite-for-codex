## Compatibility

Requires Codex's native agents, Python 3.11+ and network access (Claude consultations also need a signed-in Claude Code CLI, 2.1.280+ for Opus 5.5). Fable, Astra, SOL or Opus (5.0+) are recommended. Selected native Codex consultations returned complete adviser results with Luna 6 and High reasoning coordinating the advisers. Whether the advisers received the complete generated instructions unchanged remains unverified. These checks do not establish reliable use on other model routes or hosts.
