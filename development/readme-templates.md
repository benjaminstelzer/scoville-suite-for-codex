# Shared README sources

Both manifests resolve `shared:` entries from `../shared/readme/`. Shared blocks
cover licenses, family and member lists, Scoville installation, native Ask
installation and personal-config preservation. Names and guide differences are
manifest variables. Host requirements and development narratives remain local.

The inventory found no remaining identical active local fragments after member
names were normalized. Similar headings do not establish equivalent meaning.
Compatibility, status and provenance retain their member-specific facts.

`repository` owns the Scoville monorepo URL. Its shared suite-install block
replaces individual package lists in all nine READMEs. At the user's request,
release-facing text already uses the final repository link without temporary
creation status. This is not evidence of online availability. Creation, upload
and installation verification remain separate from this local template change.

The local build requires both the suite and sibling shared sources. Install
only exported packages. Do not upload a private source tree as a public package.
Unreferenced imported fragments are historical snapshots, not active owners.

Validation covers missing variables, confined shared paths, manifest-driven
family additions, a single suite link, retained Ask conditions, source drift and
standalone package output. No remote repository was created or published.
